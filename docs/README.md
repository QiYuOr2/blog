## 2. 变更记录约定（摘要）

- **每次改动代码行为，都在 `docs/changelog/` 追加一条记录**，不修改历史记录；后续修正另起一条并在正文互链。
- 文件名：`YYYY-MM-DD-<kebab-slug>.md`（同一天多条时顺序追加，不做数字前缀，靠文件名区分）。
- 每条记录必须包含：一句话摘要、现象、根因、方案取舍、实施步骤、验证方式、影响面与回滚。
- 写完记录后，**在本页第 1 节不改、在 `changelog/README.md` 的索引表里补一行**。

细节规则见 [changelog/README.md](./changelog/README.md)。

## 3. 写作约定

- 正文用中文，标题用短句，避免“关于……的说明”这类空标题。
- 引用代码写相对仓库根目录的路径 + 行号（如 `apps/site/src/features/weread/components/read-heatmap.vue:226`），不贴大段代码。
- 结论与数字放前面，推导过程和测量方法放同一节的后面，方便只读结论。
- 长推导、对比表格、截图清单等放 `<details>` 折叠块里；折叠块标题要能独立读懂。
- 记录里必须写清“怎么验证的”（命令、视口、数据），让下一个人能重跑。
